### 1. What is wrong, in a few words

- **Seen.** What the chart shows, in one or two sentences.
- **Expected.** What a correct chart shows.
- **Cause.** Where it goes wrong, with `file:line`. "Not traced yet" until it is known.

**Evidence.** Request `rq_…`, artifact `art_…`, if known. Name the models when the result depends on them.
